# /refine-prompt — Claude 프롬프트 개선 스킬

`lib/claude.ts` 의 프롬프트를 개선해줘.

## 대상 함수
- `refineResume` — 이력서 개선
- `feedbackAnswer` — 질문 피드백
- `generatePortfolio` — 포트폴리오 문구 생성
- $ARGUMENTS (미지정 시 세 함수 모두 검토)

## 개선 기준
1. **명확한 역할 지정** — 시스템 프롬프트에 Claude의 역할 명시
2. **출력 포맷 지정** — 마크다운/JSON 등 형식 명시
3. **한국어 응답 강제** — 모든 프롬프트에 "반드시 한국어로 답변" 포함
4. **길이 제어** — 불필요하게 장황하지 않도록 지시
5. **맥락 활용** — 이력서/질문/프로젝트 정보를 프롬프트에 효과적으로 주입

## 처리 순서
1. `lib/claude.ts` 현재 내용 읽기
2. 대상 함수의 현재 프롬프트 분석
3. 개선안 제시 (before/after 비교)
4. 승인 후 파일 수정
